# Ingenieria ETL

Para que el proceso ETL se pueda ejecutar de manera ordenada necesitamos:

1. Describirlo
2. Ejecutarlo (en alguna parte)
3. Control de tiempos.
4. Control de rendimiento.
5. No interferir con otros sistemas.
6. Observabilidad y estado ¿qué ha ocurrido? ¿ha ido todo correctamente o no?
7. Pararlo y volver a iniciar ejecución si es necesario.
8. Modificarlo, si es necesario
9. No volvernos locos con los puntos anteriores: para esto necesitamos un orquestador, y una estrategia.

**TODO ESTO es mucho más complejo** que el `happy path` y **ES UN PROCESO DE INGENIERÍA**.
