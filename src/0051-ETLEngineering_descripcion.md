# Ingeniería ETL: Descripción

Para desarrollar un proceso _formal_ de ETL tenemos que disponer de una documentación mínima que describa por lo menos:

Para cada proceso ETL:
- Descripción (QUÉ)
- Propósito (PORQUÉ)
- Stakeholders (quien se beneficia de este proceso, y a quién afecta - tanto proveedores como consumidores)
- Método (COMO)
  - Qué transformaciones se realizan.
    - Descripción del dato en origen.
    - Descripción del dato en destino.
    - Cómo se realiza la transformación de un dato a otro.
  - Que tecnologías se utilizan.
  - Qué control de calidad deben pasar
- Periodicidad y frecuencia (CUANDO)
- Dónde se encuentran los datos (DÓNDE)
- Definition of done
  - Qué criterio se debe cumplir para considerar que el proceso ETL ha sido exitoso.
- Operación
  - Procedimiento de marcha atrás.
  - Reinicio / rearmado de un proceso
